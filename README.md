An entry for the [make.fun](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a?utm_source=github&utm_medium=readme&utm_campaign=u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) office-jokes bounty: one joke about office life, a single line under 200 characters, and nothing else.

## The entry

> My boss said dress for the job you want, so I came in pyjamas — he works from home.

## What it does

`main.py` writes the entry text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` if set, falling back to `./output/entry.txt` when `/output` is not writable). It validates the text is 1–199 characters and a single line, then verifies the written file by reading it back. Deterministic, Python 3.13, standard library only — no network, no clock, no randomness.

## How to run

```bash
python3 main.py
cat /output/entry.txt   # or ./output/entry.txt if /output is not writable
```
